Dakera Helm Chart

The AI agent memory platform — deployed in seconds

Install via OCI

Recommended — no repo add needed 
# Latest
helm install dakera oci://ghcr.io/dakera-ai/dakera-helm/dakera \
  --namespace dakera --create-namespace \
  --set dakera.rootApiKey=<your-key> \
  --set minio.rootPassword=<your-password>

# Pin a version
helm install dakera oci://ghcr.io/dakera-ai/dakera-helm/dakera \
  --version 0.11.55 \
  --namespace dakera --create-namespace \
  --set dakera.rootApiKey=<your-key> \
  --set minio.rootPassword=<your-password>

Install via Helm Repository

ArtifactHub / GitHub Pages 
helm repo add dakera https://dakera-ai.github.io/dakera-helm
helm repo update
helm install dakera dakera/dakera \
  --namespace dakera --create-namespace \
  --set dakera.rootApiKey=<your-key> \
  --set minio.rootPassword=<your-password>

Upgrade

helm repo update
helm upgrade dakera dakera/dakera --namespace dakera \
  --set dakera.rootApiKey=<your-key> \
  --set minio.rootPassword=<your-password>

Key Configuration

Pass values with --set or a values.yaml file (-f values.yaml).

# Minimum required
dakera.rootApiKey: <your-api-key>
minio.rootPassword: <your-minio-password>

# Optional — expose externally
service.type: LoadBalancer
ingress.enabled: true
ingress.host: dakera.example.com

Full values reference: charts/dakera/values.yaml
