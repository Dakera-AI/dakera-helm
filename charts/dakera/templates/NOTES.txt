== v0.12 features enabled ==
{{- if .Values.dakera.features.multilingual.enabled }}
  multilingual      bge-m3, full-text language "{{ .Values.dakera.features.multilingual.fulltextLanguage }}", query language "{{ .Values.dakera.features.multilingual.queryLang }}"
{{- end }}
{{- if .Values.dakera.features.multimodal.enabled }}
  multimodal        attachments + speech to text (WAV; Whisper model via DAKERA_WHISPER_MODEL, default whisper-base)
{{- end }}
{{- if .Values.dakera.features.vision.enabled }}
  vision            image / page indexing + visual recall (a dedicated store)
{{- end }}
{{- if .Values.dakera.features.records.enabled }}
  records           multi-vector records
{{- end }}
{{- if .Values.dakera.features.lateInteraction.enabled }}
  lateInteraction   colbert-small + MaxSim
{{- end }}
{{- if .Values.dakera.features.rabitq.enabled }}
  rabitq            RaBitQ search mode (latency, not memory)
{{- end }}
{{- if or .Values.dakera.features.multilingual.enabled .Values.dakera.features.lateInteraction.enabled .Values.dakera.features.vision.enabled }}

  These change the embedding model or the lane: a FRESH store only. A pod whose model differs
  from the store's exits at startup (the log names both models); to move an existing store see
  the README, "Features in v0.12.0".
{{- end }}
{{- if eq (include "dakera.featuresNeedModels" .) "true" }}

  Models outside the image download into the model cache on first use{{ if .Values.dakera.features.prePull }} (an init container pulls them before the server starts){{ end }}.
  The first start can take minutes: /health/live is 200 meanwhile, /health/ready is 503 with the progress.
{{- end }}
  Check what is on:
    curl http://localhost:3000/v1/capabilities -H "X-API-Key: <key>"
{{- end }}

== Next Steps ==
{{- if not .Values.ingress.enabled }}
  To expose Dakera externally, enable the Ingress:
    helm upgrade {{ .Release.Name }} ./charts/dakera \
      --set ingress.enabled=true \
      --set ingress.apiHost=api.dakera.yourdomain.com

                    including config_warnings)
